Trích xuất PDF sang Excel

Đưa 1 file PDF và 1 file Excel mẫu cho AI, AI đọc hết PDF, điền đúng cột, đúng hàng và giao lại file Excel mới. Không ghi đè file mẫu, không bịa số liệu, thiếu chỗ nào đánh dấu rõ chỗ đó.

Dùng ngay miễn phí — 3 bước

  1. Lấy skill: tải file SKILL.md bên dưới, hoặc bấm Copy câu lệnh mẫu để copy toàn bộ nội dung skill.
  2. Đưa skill cho AI của bạn: trên Claude thì tải lên đúng file SKILL.md này; trên Muse AI, ChatGPT hoặc Gemini thì dán toàn bộ skill vào đoạn chat hoặc vào phần hướng dẫn của trợ lý.
  3. Gửi kèm 2 file trong cùng đoạn chat: 1 file PDF nguồn và 1 file Excel mẫu. Nội dung skill bạn vừa copy chính là câu lệnh đầy đủ, không cần thêm câu nào khác.

Trang này là 1 file tĩnh, không có máy chủ xử lý, không thu thập file hay tài khoản của bạn. Bạn gửi PDF và Excel mẫu trực tiếp trong đoạn chat với AI của bạn, không gửi lên web thinhnguyensi.com.

Skill này làm gì — quy trình 5 bước

1. Phân tích Excel mẫu

Đọc hết tên sheet, tiêu đề, tên cột, thứ tự cột và định dạng ngày tháng của file mẫu.

2. Đọc toàn bộ PDF

Đọc hết các trang, bảng và phụ lục. PDF scan hoặc hình ảnh thì dùng OCR rồi đối chiếu ký tự dễ nhầm như 0/O, 1/l.

3. Đối chiếu và ánh xạ

Căn cứ ngữ nghĩa để ghép thông tin PDF vào đúng cột Excel, không đoán mò theo vị trí.

4. Chuẩn hóa dữ liệu

Ngày tháng theo đúng file mẫu, giữ số 0 ở đầu mã số và số điện thoại, không làm tròn số.

5. Kiểm tra rồi mới giao

Đối chiếu số bản ghi PDF với số dòng đã điền, kiểm tra nhầm hàng, nhầm cột, sai số liệu trước khi giao file.

Kết quả giao

File Excel mới tên Ket_qua_trich_xuat_PDF.xlsx kèm báo cáo ngắn: số trang, số bản ghi, trường còn thiếu.

Nguyên tắc cứng của skill

  • Làm thật, giao file thật: không chỉ hướng dẫn cách làm, không chỉ trả bảng chữ trong chat.
  • Không ghi đè file mẫu: luôn tạo file mới, giữ nguyên tên sheet, tên cột, thứ tự cột và định dạng.
  • Không bịa, không suy diễn: giữ nguyên số liệu, mã số, ngày tháng và tên riêng trong PDF.
  • Thiếu thì để trống và đánh dấu [CẦN KIỂM TRA], không điền giá trị đoán.
  • Không làm mất số 0 ở đầu mã số, số điện thoại, mã định danh.
  • Không gộp, tách hay xóa dòng trùng khi chưa có căn cứ rõ ràng.
  • Xoá dữ liệu cũ chỉ xoá bảng dữ liệu: vẫn giữ nguyên khung mẫu gồm ngày tháng, tên người ký và hàng chức danh ký.

Ví dụ ánh xạ

PDF có họ tên, ngày sinh, số điện thoại, địa chỉ — Excel mẫu có đúng các cột đó thì kết quả điền chính xác như sau:

STTHọ và tênNgày sinhSố điện thoạiĐịa chỉ
1Nguyễn Văn A15/08/19900901234567TP. Hồ Chí Minh

Ví dụ này chỉ minh họa cách ánh xạ. Khi làm thật, AI căn cứ hoàn toàn vào PDF và Excel mẫu bạn gửi.

Câu hỏi thường gặp

Dùng skill này có mất phí không?

Skill và trang này miễn phí. Trang là file tĩnh, không chạy AI trên máy chủ nên web không tốn token. AI của bạn tính phí theo gói của chính bạn (nếu có).

PDF scan, PDF hình ảnh có trích xuất được không?

Được. Skill yêu cầu dùng OCR rồi đối chiếu lại ký tự dễ nhầm trước khi điền.

File Excel mẫu của tôi có bị ghi đè không?

Không. Skill luôn tạo file mới tên Ket_qua_trich_xuat_PDF.xlsx, file mẫu của bạn giữ nguyên.

Thiếu dữ liệu trong PDF thì sao?

Ô đó để trống và đánh dấu [CẦN KIỂM TRA], kèm báo cáo liệt kê trường còn thiếu để bạn kiểm tra.

File của tôi có bị gửi về web không?

Không. Trang này không có ô tải file lên và không thu thập gì. Bạn chỉ gửi file trong đoạn chat với AI của bạn.
